# Alex Play — спецификация сайта (магазин приложений)

Магазин приложений в стиле Google Play, но кроссплатформенный: iPhone (App Store) и Android (APK).
Бренд: **Alex Play**. Домен деплоя: `https://aleksejyanover.github.io/AlexPlay/`

## Данные
Единый каталог: `shared/apps.json` (массив объектов). Каждая реализация копирует/импортирует его.
НЕ дублировать данные руками — импортировать из этого файла.

### Формат объекта приложения
```
id, name, dev, emoji, grad: [цвет1, цвет2], category, rating (4.6), reviews (1200),
size ("45 МБ"), age ("12+"), version, updated, price ("Бесплатно"),
desc (длинное), shots: [{title, grad: [c1, c2]}] (3–4),
appStore (ссылка или ""), apk (ссылка или ""),
dist: [82, 10, 4, 2, 2] (%% отзывов 5..1 звёзд), tags: [], added ("2026-09-01")
```
Пустая ссылка → кнопка отображается с пометкой «Скоро» и неактивна.

## Дизайн (обязательно единый стиль во всех вариантах)
- Тёмная тема: фон `#0B0F1A`, поверхности `#141A2A` / `#1A2136`, текст `#EAEFFA`, вторичный `#8A94AD`
- Акцент: фиолетово-голубой градиент `#7C5CFF → #00D2FF`; зелёный статус `#00E5A0`
- Шрифт: системный стек (Inter, -apple-system, Segoe UI, Roboto)
- Скругления: карточки 16px, кнопки 12px, чипы 999px
- Иконки приложений: градиентный «плитка» 64–128px с emoji по центру (никаких внешних картинок!)
- Скриншоты: стилизованные «плитки» 9:16 (или 16:9) с градиентом, эмодзи и заголовком — тоже без внешних ассетов
- Анимации: hover-подъём карточек (translateY(-4px), тень), плавные переходы 0.2s

## Страницы / функции (полноценный магазин)
1. **Главная (`/`)**: header (логотип Alex Play + поиск + навигация), hero-баннер с избранным приложением,
   чипы категорий, секции-карусели: «Популярные», «Новинки», «Топ по рейтингу», «Игры», «Приложения».
   Карточка приложения: плитка-иконка, название, разработчик, рейтинг ⭐, категория.
2. **Категории**: страница/фильтр со всеми категориями (Игры, Инструменты, Фото, Погода, Финансы,
   Образование, Здоровье, Музыка, AI...), сетка приложений выбранной категории.
3. **Поиск**: живой фильтр по названию, разработчику и тегам (поиск прямо в header, результаты на
   отдельной странице/состоянии, счётчик «Найдено N приложений», состояние «Ничего не найдено»).
4. **Страница приложения (`/app?id=...`)**: большая плитка, название, разработчик, рейтинг
   (число + звёзды + гистограмма по 5..1 звезде + «N отзывов»), метаданные (размер, возраст,
   версия, обновлено, категория, цена), галерея скриншотов (горизонтальный скролл), описание,
   «Что нового», теги, похожие приложения, две кнопки загрузки:
   - **Загрузить для iPhone** (App Store) — акцентная
   - **Скачать APK (Android)** — контурная
5. Footer: Alex Play, ссылки (О проекте, Разработчикам, Политика, © 2026).

## Технические требования по вариантам
- **html**: чистые HTML/CSS/JS, страницы `index.html` + `app.html`, `data.js` (`window.APPS = [...]`),
  `app.js` (роутинг через query-параметры, поиск, фильтры). Никаких зависимостей.
  Базовый путь деплоя: `/AlexPlay/html/`.
- **react**: Vite + React (JSX), hash-роутинг (#/ , #/app/:id , #/c/:cat , #/search?q=),
  `base: '/AlexPlay/react/'`, библиотек не нужны (кроме React). Сборка `dist` копируется в `react/`.
- **next**: Next.js App Router, `output: 'export'`, `basePath: '/AlexPlay/next'`,
  динамический маршрут `/app/[id]` с `generateStaticParams`, static export → `next/`.

## Важно
- Только латиница/кириллица в UI — русский язык интерфейса.
- Адаптивность: mobile (≤640px), tablet, desktop — сетки 2/3/4/5 колонок.
- Ссылки наружу: `target="_blank" rel="noopener noreferrer"`.

## Addendum (обязательно применить) — приложения автора, платформы, работающие футеры

### 1. Новые поля данных (уже есть в shared/apps.json)
- `author: true` — приложение создано автором Alex Play (6 таких приложений: atrium, telefamily, hotkeys-trainer, gta-alex, fake-virus-prank, soundsmith).
- `links: { ios, android, mac, windows }` — ссылки загрузки ПО ПЛАТФОРМАМ (поле `appStore`/`apk` УДАЛЕНЫ, используйте только `links`). Пустая строка → кнопка неактивная с пометкой «Скоро».

### 2. Главная: авторская секция (сразу после hero-баннера)
Блок `.author-band` (см. эталон html/css/style.css): тёмная карточка с фиолетово-голубым свечением,
слева «фоточка» — градиентный квадрат 62px с ▶ (класс .author-photo), заголовок «Создано автором Alex Play»,
подзаголовок «Собственные проекты автора магазина — уже здесь», справа синяя печать-пилюля
«✦ Создана автором Alex Play» (.author-seal), ниже сетка карточек всех author-приложений.

### 3. Карточки и страница приложения
- На карточке приложения при `author:true` — угловой бейдж «✦ Alex Play» (градиентная пилюля, .badge-author).
- На странице приложения рядом с названием такой же бейдж.
- Под шапкой — блок .author-note: «фоточка» ▶ + текст «Создано автором Alex Play — авторский проект, созданный разработчиком магазина Alex Play.»

### 4. Кнопки загрузки — 4 платформы (сетка 2×2, .dl-grid)
- «Загрузить для iPhone» (links.ios, акцентная btn-primary)
- «🤖 Скачать для Android» (links.android, контурная)
- «🍎 Скачать для Mac» (links.mac, контурная)
- «🪟 Скачать для Windows» (links.windows, контурная)
Под ними подпись «Доступно на iPhone, Android, Mac и Windows».
Пустая ссылка → disabled кнопка с «· Скоро». Внешние ссылки: target=_blank rel=noopener noreferrer.

### 5. Работающие ссылки футера (вместо href="#")
- «О проекте», «Разработчикам», «Политика конфиденциальности», «Поддержка» — ведут на настоящие страницы с текстом-эталоном из html/about.html, html/developers.html, html/privacy.html, html/support.html (прочитать их).
  - react: маршруты #/about, #/developers, #/privacy, #/support (страницы-компоненты, текст как в эталонах).
  - next: статические страницы /about/, /developers/, /privacy/, /support/ (app/about/page.js и т.д., generateStaticParams не нужен).
- Поиск в header информационных страниц: Enter → на главную с ?q= (или hash-поиск).

### 6. Эталон
Все стили/разметка сверяй с реализацией в папке html/ (css/style.css, js/app.js, js/detail.js, about.html и др.).
После изменений: пересобрать и скопировать dist → react/ (vite base '/AlexPlay/react/'),
out → next/ (basePath '/AlexPlay/next'). Git-коммиты делает координатор, не коммить.
